## Colorimetry and color management

Printing is recreating colors of nature.

### Color models

Process to create multiple colors from primary colors. Widely used color models are:
* Additive synthesis: Light allows color to be displayed (RGB), mixing red, green and blue in different combination and at different levels of intensity
* Subtractive synthesis: Pigments (inks, toner, etc) are used to reproduce color, in printing process the color model is CMYK, Cian, Magent, Yellow, Key (Black)

Both systems use primary colors, when combined, produce a huge number (range) of colors.

## Color Space
