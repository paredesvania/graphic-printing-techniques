## Software matters!!

And the workflow matters even more.

## Adobe Creative Cloud

Offers the professional suite of tools for the entire graphic production chain. it **represent the international reference standard.**

### Photoshop

Photo retouching and raster (pixel) graphic software.

Basic rules for printing:

* CMYK color mode
* standard resolution 300DPI at a 1:1 scale relative to the final print size
* **Avoid inserting text in photoshop**, it will be rasterized, losing path sharpness during the printing phase.

#### File formats

* .PSD -> Photoshop Document, native format, preserves  all adjustable layers, masks, effects and masks.
* .PSB -> Photoshop Big, extension of .PSD format for huge file sizes (over 2GB or 300.000 pixels)
* .TIFF -> Tagged Image File Format, the standard professional lossless format for printing. Never lose quality, it is the ideal format to insert as links in InDesign
* .JPEG -> Joint Photographic Experts Group, lossy compressed format, great for quick downloading and web sharing.
* .PNG -> Portable Network Graphics, lossless format born for the web that supports pixel-based transparency, it should not be used for printed.
* .GIF -> Graphic Interchange Format, web format with. limited palette, exclusively for lightweight graphics and small digital animations.
* .PDF -> Portable Document Format, allows saving the project while maintaining some vector and text functions. Do not replace the final PDF generated by InDesign.
* .WEBP -> developed by google, optimizes images file weight to the maximum to speed up the web, foreign to the printing world.
* .RAW -> format that retains all the image data captured by digital camera, allows working on images without loosing the original shooting data (heavy).

### Illustrator

Vector graphic software based on mathematical formulas, it guarantees perfect scalability of elements without losing quality.

**Professional workflow:** complex elements created in illustrator should never been copied and pasted into InDesign, rather be linked.

#### File formats

* .AI -> native vector format, preserves all layers, paths, masks, graphic styles, etc. intact
* .EPS -> Encapsulated PostScript, Universal standard vector format
* .PDF -> Portable Document Format, allows saving the project while maintaining some vector and text functions. Do not replace the final PDF generated by InDesign.
* .SVG -> Scalable Vector Graphics, developed for responsive web.
* Raster Exports (.TIFF, .JPEG, .PNG) -> Illustrator allows rasterizing vector paths into pixel-based images. For social media, websites or digital presentations.

### InDesign

The hub of desktop publishing. It is the final assembly, it is designed specifically for managing complex multi-page documents. It is the only ones that allow us to see the bleed, crop marks and grid.

#### File formats

* .INDD -> native working format, preserves page structure, grids, written texts, styles, and the map for external links.
* .IDML -> InDseign Markup Language, lightweight XML file, it allows opening a current project even with very old versions of the software.
* .PDF -> Portable Document Format, the only final output for printing.
* .EPUG / Images (.JPEG, .PNG) -> Alternative export format, avpide for printing.
* .INDT -> InDesign Template, used for creating predefined layout templates that cannot be accidentally overwritten.

## Adobe Acrobat

Is the universal and independent standard for reliable document exchange. It guarantees perfect visual uniformity on every device or operating system.

#### File formats

* .PDF -> Native format, designed to present documents consistently across different platforms and devices.
* .PDF/A -> for long term document archiving, disables interactive features or unembedded external fonts.
* .PDF/E -> For technical and engineering documentation (3D models and CAD diagrams)
* .PDF/UA -> Universal accessibility to ensure correct reading by screen readers for visually impaired people and others.
* .PDF/X-4 -> Mandatory standard for commercial printing, it mandates the inclusion of bleeds, manages output color profiles and supports native transparency.
