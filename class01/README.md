Forget about the results on the screen.

## Common file errors

* Low resolution or pixelated images
* RGB colors instead of CMYK
* Missing or non-embedded fonts (always do it)
* Lack of bleed and crop marks
* Lalyout and margins not conforming to print specifications
* Files not in a production-compatible format

>**PDF:** Printed document format

## Goal

Learn to prepare proper, print-ready files for any kind of printing process

### Exam

Using a branding we have made, 4-5-6 things to produce.

Create a PDF presentation talking about the brand.
